# Prompt library

Original, reusable prompts for code-rendered motion graphics. These are **new templates**, not copies of creators' prompts. The linked examples show a visual direction; follow each link to see whether the creator published their actual prompt. A reference is inspiration, not a request to reproduce its assets, brand, character, or exact shots.

## How to use

1. Open a style file and replace every `[placeholder]` with your subject, copy, assets, and constraints.
2. Give the agent the actual assets and a permitted music track if the prompt calls for them. Remove any scene you cannot support with real content.
3. Ask for a storyboard or beat map first. Review one rendered draft, then give specific notes about timing, readability, composition, and sound.
4. Use a renderer such as [Remotion](https://github.com/remotion-dev/remotion) or [HyperFrames](https://github.com/heygen-com/hyperframes) when you need repeatable frame timing and an exported video.

For more creator examples, browse [ClaudeVideo's video index](https://claudevideo.org/videos) and [prompting guide](https://claudevideo.org/guides/claude-opus-5-5-video-prompts).
