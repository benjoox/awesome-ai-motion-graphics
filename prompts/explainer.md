# Explainer

**Reference:** [Five-scene business explainer](https://claudevideo.org/videos/five-scene-explainer-template-demoed-for-an-ai-tool-service) — creator example with a published prompt.

```text
Create a [45]-second visual explainer that teaches [one concept] to [audience]. The accurate source material is [source or notes]. The viewer should be able to answer [one test question] afterward. Do not add claims beyond the source.

Write a concise narration draft and a scene outline before building. Use this teaching arc: familiar situation, the key mechanism, one worked example, and a recap. Show one idea at a time. Use labels, diagrams, and motion to clarify cause and effect; avoid long paragraphs on screen. Leave room for the viewer to absorb each step.

Visual style: [palette, typography, illustration technique]. Stage: [size] at [fps]. Use the supplied narration audio if present; otherwise output a script with timing markers and leave audio optional. Keep all motion tied to explicit time. Render a preview, check that every diagram agrees with the narration, then export.
```
