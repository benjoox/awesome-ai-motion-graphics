# Depth hierarchy

**Reference:** [Miguel07Code's depth-as-hierarchy film](https://x.com/Miguel07Code/status/2105453292008661458) — a code-rendered [HyperFrames](https://github.com/heygen-com/hyperframes) example. The linked post includes the creator's concept and implementation notes. Use it as a visual reference; this template is newly written.

```text
Make a [duration]-second 3D motion piece about [one subject or data reading]. The audience should discover [main takeaway] as the camera changes focus and moves through depth.

Build one coherent object or environment with [three] readable depth planes. Show the same underlying subject on every plane, adding a specific layer of detail at each depth: [essential fact], [context], then [supporting evidence]. Keep the data and labels consistent across all views. Write the exact on-screen copy and assign each reveal a time range before animating.

Use optical focus, occlusion, refraction, and camera distance to guide attention. Keep type scale and position mostly stable so the depth change carries the hierarchy. Allow each plane to settle long enough for its words to be read before shifting focus. Make the transition between planes reveal a meaningful new fact, not just a new angle.

Use a fixed [aspect ratio], [fps], and a restrained [palette/material] system. If using HyperFrames or Three.js, make camera, focus, lighting, and object state deterministic functions of time so any frame can be rendered directly. Check first, middle, and final frames for legibility, overlapping labels, and confusing depth of field. Deliver source, a timed beat sheet, and an exported [MP4/WebM].
```

The reference's specific tide reading, three-window instrument, closing inscription, and shot sequence belong to that work. Substitute your own subject, information structure, and visual identity.
