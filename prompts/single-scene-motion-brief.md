# Single-scene motion brief

**Inspiration:** [Charlie Hills's public Claude Motion starter brief](https://charliehills.substack.com/p/claude-motion-graphics). This is an original template for a code-rendered motion study, not a copy of his prompt.

~~~text
Create a [duration]-second motion study for [audience] about [subject]. The intended takeaway is [one idea the viewer should understand]. Use only these verified facts and exact words: [facts and on-screen copy]. Ask for missing facts instead of inventing product behavior or claims.

Inputs: [canvas size and aspect ratio], [brand colors and type], [supplied assets and their permissions], [audio or silence], [target frame rate], and [renderer or code environment]. Deliver [video format and resolution] plus editable source and render instructions.

Scene: [one focal object or element] changes from [starting state] to [ending state] because [visible action or cause]. Keep [essential visual properties] consistent through the change. The focal element should be large enough to read at [smallest viewing size]. Add supporting elements only when they clarify the action.

Before building, propose a timed plan with a setup, the action, and a readable hold on the result. Give each phase a start and end time. Reserve enough time for the supplied words and the final state to be understood. If this should loop, plan the return to the opening state and match position, motion, content, and audio at the seam.

Visual direction: [specific materials, depth, lighting, typography, and palette]. Motion direction: [how the object accelerates, changes, and settles]. Constraints: [unwanted effects or assets], [accessibility or legibility requirements], and [facts or wording that must stay exact]. Use springs or fast cuts only when they help the action read.

Render stills at the start, key action, result, and loop seam if applicable. Review them at full size and at [smallest viewing size]. Then inspect consecutive frames around transitions and watch the complete render with sound. Fix clipped copy, unclear cause and effect, uneven holds, or a visible loop seam before delivery.

Deliver the timed plan, editable source, asset and source credits, render instructions, and final [format] video. State any unverified behavior or review limitation.
~~~
